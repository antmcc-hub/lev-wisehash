# Licensing Note

The WiseHash source repositories reviewed for this package are public and use Apache-2.0, not MIT.

## MIT vs Apache-2.0

Both MIT and Apache-2.0 are permissive open-source licenses. They generally allow use, copying, modification, distribution, and commercial use.

| Area | MIT | Apache-2.0 |
|---|---|---|
| Simplicity | Very short and broad | Longer and more explicit |
| Attribution | Keep copyright and license notice | Keep copyright and license notice, plus NOTICE handling when present |
| Patent grant | Not explicit | Explicit patent license from contributors |
| Patent retaliation | No explicit patent retaliation clause | Patent license can terminate if you sue over patents |
| Enterprise reuse | Good | Often clearer for companies because patent terms are explicit |

## Practical Read

- MIT is simpler.
- Apache-2.0 is usually stronger for serious reuse because it includes an explicit patent grant.
- Because WiseHash uses Apache-2.0, this package keeps Apache-2.0 licensing and includes a NOTICE file with attribution.
- If this package is copied back into WiseHash, Ashton can keep Apache-2.0 and replace LEV-specific wording with WiseHash-native wording.
