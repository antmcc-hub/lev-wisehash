# lev-wisehash Agent Instructions

This public repository is a standalone Codex marketplace for WiseHash dispatch and MCP patterns.
It is a small adapter, not an orchestration runtime.

- The plugin, shared templates, and JSON schemas live in `plugins/lev-wisehash/`.
- Repository skill copies live in `.agents/skills/`.
- Cowork upload artifacts live in `dist/*.skill`.
- Keep plugin skills, repository skill copies, and packaged artifacts in step when changing skills.
- Preserve `NOTICE` and `LICENSE`, including their attribution and license notices.
- Keep all contributions public-safe; never add secrets or private information.
- Do not include client or person names, internal hostnames or paths, account names, or ticket IDs.
